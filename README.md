# Harry Aiken — Independent Research

A responsive research portfolio covering financial markets, sovereign and credit risk, geopolitical intelligence, OSINT, and quantitative analysis.

## Website structure

- `index.html`: homepage and project navigation
- `projects/`: five project briefs; planned work is clearly marked
- `assets/style.css`: mobile-friendly design
- `assets/app.js`: menu, project filters and contact links
- `assets/config.js`: edit the email, LinkedIn and GitHub links
- `templates/research-report-template.md`: reusable report outline

## Publish with GitHub Pages

In repository **Settings → Pages**, set **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)**, and save.

Once enabled, the expected URL is:
https://harryaiken4-creator.github.io/research-portfolio/

## Before sharing with employers

Add your preferred professional contact details to `assets/config.js`; carefully review personal details on the homepage; replace planned briefs with evidence-backed publications as projects are completed; check sources and ensure you have the right to publish data.

**Do not present draft work as completed research or confidential intelligence as publicly releasable material.**
